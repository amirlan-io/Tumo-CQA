# Аудит фронтенда — 7 ноября 2026

Исправлено:
- Смена версии очищает прошлый результат и ручную форму.
- Поздний ответ открытия диалога игнорируется после выбора другой карточки или ухода со страницы.
- Поздняя оценка ИИ не подменяет результат другой выбранной версии.
- Старое завершение запроса не стирает актуальное сообщение об ошибке.
- Разделы отражаются в hash URL и поддерживают возврат через историю браузера.
- Неожиданный не-JSON ответ сервера получает понятное сообщение.

Все 18 тестов проекта проходят.

Ранее визуально проверены главный экран, редактор и демонстрационный результат в браузере на узком и широком экране. Этот аудит функциональный: не утверждается проверка каждого сочетания ответов, каждой клавиши, всех мобильных устройств или доступности внешних аудиоссылок. Реальные вызовы ИИ по-прежнему требуют модуль друга.
