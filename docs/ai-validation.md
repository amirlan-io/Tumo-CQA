# Отчёт проверки AI-модуля

Дата: 2026-11-07. Исходная ветка: `backend`, базовый commit `a51b37593bb36de513c940fbfbfb4c7cfb16784c`. Среда: Linux, Node.js `v26.13.0`, npm `12.2.2`.

## Реальная проверка Crouton v1: интеграция PASS, качество требует доработки

После добавления пользователем ключа выполнены настоящий одиночный вызов и предварительный benchmark на 9 диалогах через OpenRouter `stealth/crouton-alpha` / провайдер `Stealth`. Промпт и схема между вызовами не менялись. Ключ не выводился, исходные ответы сохранены в закрытом `data/`.

Локальный сервер не был запущен. Для проверки использовалось существующее Express-приложение на свободном loopback-порту с изолированной БД в памяти. Версии получены через `GET /api/checklists` и `GET /api/checklist-versions/:id`, содержимое критериев соответствует первоначальному snapshot. Рабочая SQLite, маршруты и `.env` не изменены. UUID этих версий относятся к временной БД, уже закрытой; для рабочего сервера нужно получить его собственный UUID.

Первый вызов `p1-ru-001`: 8 результатов, валидный JSON с первой попытки, **8978 мс**, стоимость по `usage.cost` — **$0**. Содержательно есть расхождение по завершению: модель засчитала одно прощание как выполнение составного критерия. Поэтому успешная схема сама по себе не означает правильность всех восьми оценок.

| Модель | Выполнено RU / KZ / EN | Совпадения answer + raw_score с draft | Расхождения RU / KZ / EN | Неподтверждённые обоснования | Среднее время | Ошибки JSON / контракта |
| --- | --- | --- | --- | --- | --- | --- |
| `stealth/crouton-alpha`, v1 | 3 / 3 / 3 | **56 / 72 (77,8%)** | **7 / 2 / 7** | **6**, по агентскому аудиту | **8814 мс** | **0 синтаксических / 2 контрактных**, исправлены repair |
| `openai/gpt-4.1-mini` | не запускалась | не измерено | не измерено | не проверено | не измерено | не измерено |

**77,8% — совпадение с предварительной агентской разметкой, не точность на согласованном людьми gold.** 16 расхождений нуждаются в решении команды. Ни одного сетевого/HTTP-сбоя в этом прогоне; все 9 диалогов получили валидный итоговый JSON. Было 11 запросов на benchmark: в звонке `p4-ru-001` и чате `p1-kz-003` модель пропустила обязательный `checked_range` для частичной шкалы, оба раза один repair исправил контракт. Ошибок синтаксиса JSON не было. Время включает repair: минимум 6704 мс, максимум 12147 мс. По всем 12 HTTP-ответам, включая первый отдельный вызов, суммарный `usage.cost` равен **$0**.

Независимый агентский аудит проверил 72 результата против всех 166 исходных реплик: не обнаружил вымышленных номеров/цитат в evidence в принятой узкой категории, но отметил **6 неподтверждённых утверждений в explanation** (RU: 3, KZ: 2, EN: 1), включая выдуманное извинение и превращение обещанной передачи вопроса в выполненную. Это **не human approval** и не гарантия верности всех ссылок. 57 расхождений наборов evidence с draft не считаются автоматически ошибками.

Проблемы качества: подмена составного завершения одним прощанием; нестабильное различение `yes` и N/A при уже достаточном контексте; перенос оценки содержания на ясность общения; выбор шкальной ступени не по конкретному описанию; чрезмерная уверенность по ASR и правилам компании. Промпт v1 оставлен неизменным, чтобы не подменять baseline результатами настройки на тех же девяти примерах.

## Подготовка данных: PASS, gold требует согласования

- Получен DEV-набор по ссылке из PDF: 65 диалогов, 35 RU / 15 KZ / 15 EN, 60 чатов и 5 звонков.
- Пользовательский `invoke.json` полностью совпадает с полученными записями, включая содержимое всех 65 записей.
- Выбрано 9 реальных диалогов, по 3 на язык, включая звонок, N/A, непроведённую идентификацию и грубые нарушения.
- Предварительная разметка: **72/72 ответа проходят структурную и конфигурационную проверку** `createOutputContract` на исходных диалогах. Это не точность модели.
- Разметка имеет `status=draft`, `approved_by=null`. Она подготовлена агентом и **не согласована людьми**. Спорные условия завершения, ASR и непроверяемые внутренние правила перечислены в [ai-gold-review.md](ai-gold-review.md).
- Benchmark без `--allow-draft` отказывается использовать такой эталон. При смене критериев необходима новая разметка.
