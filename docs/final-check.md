# Проверка перед защитой — 8 ноября 2026

> Исторический отчёт участника для его локальной базы. Актуальная проверка нашей копии: [tz-audit.md](tz-audit.md). Оценки и аудиоданные не переносятся через Git.

Проверяется прототип на Node.js + SQLite + HTML/CSS/JavaScript без сборщика. Вход для демо не требуется; сервер по умолчанию слушает только 127.0.0.1.

- В браузере открыты RU/KZ/EN, звонок, исходные и пересмотренные оценки, ссылки на доказательства, чек-листы и песочница весов.
- Новый вымышленный диалог оценён реальной моделью: исходная версия 100.00, изменённая версия 92.31. Новое правило о сроке ответа получило «Нет», исходная оценка осталась доступной. Первый запрос изменённой версии завершился тайм-аутом; повтор прошёл.
- После повторов только ошибочных заданий последние оценки DEV полностью готовы по обеим проверенным рубрикам: исходная v1 — 65/65, изменённая v3 — 65/65. Старые неудачные пакеты сохранены как история.
- Исходный DEV-набор экспортируется: 65 успешных результатов. Это техническая полнота, не доказательство точности всех вердиктов модели.
- Независимый пересчёт 266 исходных/итоговых баллов сохранённых оценок: расхождений нет.
- Предпросмотр весов на 65 диалогах: без изменений 84.65 → 84.65; перенос 5 единиц веса с выявления потребности на контакт — 84.65 → 85.02. Версии и оценки предпросмотр не меняет.
- Ширина 390 px: проверены список, режим CRM и редактор шкал без горизонтального переполнения.

## Исправления по результатам аудита

- Аудиофрагмент сам останавливается; обработчик удаляется до pause, исключая повторный timeupdate за границей массива. Закрытие карточки, смена раздела, уход/скрытие страницы останавливают звук. Поддержаны ISO и относительные временные метки.
- Результат показывает собственное название и версию чек-листа. История переключает выбранную версию. Кнопка результата пакета открывает соответствующую оценку, а не произвольную последнюю.
- Подпись апелляции сразу обновляется после решения; исходные ответы и баллы сохраняются.
- Некорректные записи импорта, включая null и неверный audio_url, возвращают 400 без частичной записи.
- У каждого задания пакета указан диалог. «Повторить только ошибки» создаёт отдельный пакет только для неудачных заданий, сохраняя исходный журнал. Уже успешные оценки не запускаются повторно.
- Баллы до нормализации и вклад после N/A подписаны отдельно.
- Учебный тренер доступен для отрицательных ответов, неполных шкал и грубых ошибок. Он показывает правило, исходное объяснение, доказательство и безопасный шаблон на языке диалога. Это шаблон, не дополнительная генерация ИИ.

## Честные ограничения

- Метки транскрипта не являются гарантированным выравниванием аудио по словам. Позиция считается относительно первой метки; паузы/монтаж записи могут сместить звук. Интерфейс явно предупреждает об этом и сохраняет прямую ссылку на запись. Точное совпадение речи с текстом требует offset/end от источника или отдельного выравнивания.
- Провайдер ИИ может отвечать с задержкой или некорректно. Ошибка видна и не превращается в нулевой балл; доступны повтор и диагностика в приватном data/.
- Проверка схемы и доказательств не гарантирует правильность финансовых советов. Человек принимает решение по спорным ответам.
- Режим Dynamics 365 — предпросмотр компактного интерфейса. Развёртывание и авторизация в CRM не проверялись и не входят в сдачу.
- Telegram-рассылка не входит в этот релиз. Автоматическая передача реальных разговоров во внешние мессенджеры не включена.
- Внешние вкладки, открытые по прямой ссылке на запись, управляются браузером: приложение не может остановить их плеер.

## Повторная проверка

```sh
npm ci
npm test
cp .env.example .env
# Заполнить .env локально. Не публиковать ключи и подписанные ссылки.
npm start
```

Открыть http://127.0.0.1:3000/frontend/. Для ИИ нужны AI_ENABLED=true и настройки из docs/ai.md. Для организаторов — ORGANIZER_API_URL. Подготовить новый вымышленный диалог, оценить по исходной версии, изменить правило и сохранить новую версию, переоценить тот же диалог, открыть историю. Подать апелляцию по критерию и проверить решение с причиной и оба итога.

На защите не менять исходную рубрику для официального экспорта: для экспериментов создайте отдельный чек-лист. Реальные разговоры, диагностические ответы модели, SQLite и .env остаются вне Git.
