# Проверка обязательного ТЗ — 7 ноября 2026

## Реализовано

1. Начальный чек-лист: восемь критериев, веса, ступени, условия N/A, отдельный флаг грубых ошибок. Создание отдельного чек-листа и сохранение новых неизменяемых версий через интерфейс. Замена критерия подтверждена DOM+HTTP тестом; старые оценки сохраняют старую версию.
2. Загрузка через GET организаторов по group_id и JSON-файл через интерфейс. RU/KZ/EN, роли и исходное время сохраняются. Повторный импорт без дублей. Реальный DEV ранее проверен: 65 записей.
3. Выбор версии и запуск оценки, очередь и статусы. Настоящий модуль ИИ ещё не подключён; вместо скрытой имитации возвращается 503. Подготовленные ответы обозначены как демонстрационные.
4. Результаты: исходные и текущие ответы, веса, вклад, объяснения, ссылки на реплики, причины N/A и проверенные диапазоны. Сервер проверяет цитаты и границы диапазонов. missed_action=true требует диапазон. Семантическую полноту доказательств должна обеспечить модель.
5. Подсчёт: веса и шкалы, N/A, секции, два знака, null при отсутствии применимых весов; грубая ошибка отдельно. Пример 59.41 и крайние случаи покрыты тестами.
6. Карточка: транскрипт и результаты, подсветка доказательств; для звонков audio controls и ссылка на исходную запись. Работоспособность внешних аудиоссылок зависит от организаторов; фактическое воспроизведение каждого звонка не проверялось.
7. Апелляция: критерий, комментарий, фрагмент, подтверждение/изменение с причиной. Итог пересчитывается, исходная оценка сохраняется, решения показываются в результате. Повторное подтверждение не отменяет прошлое изменение.
8. HTML/CSS/JS отдельно от API, без CDN. Авторизация не нужна. Код в открытой ветке backend, README и API-контракт доступны.

## Проверки

18 автоматических тестов проходят: арифметика, API, ошибки организаторов, статусы, пакет, кэш, апелляции, доказательства, сохранность SQLite после повторного открытия, интерфейс с настоящими HTTP-запросами и заменой критерия. Модуль модели в тестах подменён. DOM-проверки jsdom не заменяют визуальную проверку браузером; дизайн ранее просматривался в браузере отдельно.

- Совместно проверить чистый запуск по README, согласовать итоговое объединение в main и стоп-коммит, отправить ссылку организаторам и отрепетировать защиту.

Полная готовность к защите не заявляется до проверки настоящего ИИ и сквозного сценария на контрольных данных.
