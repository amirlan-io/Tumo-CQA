# Сверка с ТЗ — 8 ноября 2026

Реализованы импорт GET по group_id и JSON, RU/KZ/EN, восемь исходных критериев и изменяемые версии, настоящая оценка OpenRouter, статусы, пакеты и кэш. Сервер рассчитывает веса, N/A, секции и отдельный флаг грубой ошибки. Есть доказательства, аудиоплеер, апелляции, причины решений, исходный и финальный результат. Интерфейс HTML/CSS/JS, авторизация для демо не требуется.

Дополнено: защита несохранённых правок редактора, скачивание CSV и официального JSON через интерфейс, учебные примеры по критериям. Новые произвольные правила требуют индивидуального примера: универсальная подсказка не выдаётся за проверенный ответ.

234 теста прошли. Проверки jsdom охватывают редактор и экспорт с ошибочными записями. В браузере ранее проверены оценка, доказательства и апелляция с пересчётом 92,31 → 100; после последних изменений подтверждено появление предупреждения редактора. Повторно проверены реальные скачивания CSV (69 оценок) и JSON (65 уникальных DEV, 0 ошибок), предупреждение о неполном JSON, обязательные поля нового критерия, удаление черновика, сохранение новой версии и навигация. Системное окно подтверждения ранее блокировало инструмент браузера; отмена и сохранность черновика проверены автотестом.

В нашей локальной базе 65/65 DEV оценены по исходной версии. Контрольная группа ещё не загружена. Наличие оценок изменённой версии в базе другого участника не подтверждает их наличие здесь.
