# Сверка с планом действий команды

Изучен PDF «CQA_Hackathon_план_действий», 24 страницы.

Готово: импорт по group_id; неизменяемые версии чек-листа; проверка шкал и N/A; подсчёт весов, секций и итогов; апелляции, решения и история; карточка проверяющего; экспорт CSV; SQLite WAL и busy_timeout.

Следующее: согласовать Node.js или миграцию на FastAPI; LLM-шлюз и контракт с участником по моделям; сохранение модели и версии промпта; проверка цитат и диапазонов; очередь пакетных оценок; кэш по содержимому диалога, конфигурации, модели и версии промпта; статичный фронтенд от его владельца; проверка запуска с нуля.

Модели, квоты, лицензии и заявления о критериях жюри в плане не считаются независимо подтверждёнными. Проверить официальную документацию перед реализацией соответствующего провайдера. SSH, настройки учётных записей и защиты main не изменялись.

Пример расчёта из раздела 5.4 включён в автоматические тесты: 50.5 × 100 / 85 = 59.41. Неверную ступень шкалы сервер отклоняет: автоматическое округление ответа модели до ближайшей ступени может скрыть ошибку и пока не применяется.
